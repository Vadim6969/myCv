# Резюме — Вадим Ахтаров

Одностраничный сайт-резюме. Статика: HTML + CSS + немного JS, без сборки.

## Запуск

Просто открыть `index.html` в браузере. Или локальный сервер:

```bash
python3 -m http.server 8000
```

## Что где

| Файл | Зачем |
|---|---|
| `index.html` | Весь текст резюме: шапка, опыт, стек, образование, контакты |
| `projects.js` | **Проекты — единственное, что нужно заполнить.** Инструкция внутри файла |
| `styles.css` | Оформление (всегда светлая тема) и стили для печати |
| `main.js` | Рендер карточек проектов и анимации. Трогать не нужно |
| `assets/akhtarov-vadim-cv.pdf` | PDF-резюме для кнопки «Скачать» |

## Как добавить проект

Открыть `projects.js`, заполнить объект по шаблону, сохранить, обновить страницу.
Пустые `{ slot: true }` — заглушки «свободный слот», их можно удалить.

Сильная карточка = задача → что сделал → результат в цифрах.
Например: «Таблица на 50k строк тормозила — внедрил виртуализацию AG Grid,
время рендера упало с 4 с до 400 мс».

## Публикация

Подойдёт любой статический хостинг: GitHub Pages, Vercel, Netlify, Cloudflare Pages —
закинуть папку целиком, сборка не требуется.
